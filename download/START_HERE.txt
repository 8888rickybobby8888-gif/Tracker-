WHAT IS IN THIS FOLDER
  *.py                 run on the COMPUTER (Python 3). Install once:  pip install -r requirements.txt
  my_chase.py          YOUR chase code (edit this one)
  markers/             THE TOWER: marker_0 = FLAT on top of the tower (top edge to the rover's front), marker_1 = LEFT face, 2 = BACK, 3 = RIGHT (no front face); marker_8 = flat on the floor; markers_sheet.pdf has all five
                       (python make_markers.py --size 0.05 to print them at 5 cm; set MARKER_SIZE to match in tracker.py or on the Settings page)
  esp32/rover_esp32/   THE ESP32 PROGRAM: open rover_esp32.ino in the Arduino IDE, edit WIFI_SSID / WIFI_PASS, upload (steps at the top of the file and in README.md,
                       including what to do when the IDE cannot see the board). The rest of esp32/ (espnow_bridge/, cam_espnow.h, lidar_test.ino) is optional
  docs/                WIFI_VS_ESPNOW.md (setup + comparison), CODE_TOUR.md, EXPERIMENTS.md
  settings page        in the dashboard header: every variable, Save writes settings.json (loaded at start)
  README.md            Quick start and every option. HANDOFF.md = project state.

FIRST RUN
  1. pip install -r requirements.txt
  2. python mark_arena.py        (or scan_arena.py) to save arena.json
  3. python follow.py                 (camera 0; or --camera 1) opens the DASHBOARD in your browser (rover ID box, START/PAUSE/STOP, camera, map, lidar...)
     python follow.py --camera 1 --onboard http://<esp32-ip>:81/stream     tandem with the rover's own camera
Not included on purpose: the simulator and tests (simulate.py, sim_world.py, tests/, run_tests.py, sim_output/). Get them from the repo.
